# Scope and publishing rules

Change only jane-wang-art/jane-wang-art.github.io for this website unless the owner authorizes otherwise. The separate jane-frank-artwork repository is the authoritative artwork archive; read it but do not change it while maintaining this blog. Do not alter Frank's blog.

Preserve artwork. Never redraw, crop, replace or add third-party reference art without approval. WebP display derivatives may be resized from the explicitly published PNGs; keep original PNG bytes and verify SHA-256. Do not publish private conversations, rejected drafts, personal records or secrets.

Artwork credit: Jane Wang. Copyright identity: jane-wang-art. Source: https://github.com/jane-wang-art/jane-frank-artwork. Keep paid written permission plus visible audience-facing attribution; do not add a free-use or open-source artwork license.

Hexo source is on main. The generated gh-pages branch and GitHub Pages artifact are build outputs. Do not hand-edit them. Validate routes, all nine images, mobile layout and lightbox behavior. Do not claim the site is live until the deployed URL is checked.
